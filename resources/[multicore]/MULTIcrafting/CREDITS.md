# Credits for MULTIcrafting

MULTIcrafting is GPL v3, part of MULTIcore. Its code is written fresh for MULTIcore.

## RSG v2 (GPL v3), by Rexshack-RedM, RexShack and their contributors
Used for game facts only; no code is copied:
- `config/stations.lua`: the saloon and gunsmith counter coordinates. They are the store points in rsg-shops'
  config (`Config.StoreLocations`), as MULTIstores uses them.
- The scenario `WORLD_HUMAN_CROUCH_INSPECT`, which several RSG v2 scripts play for work done crouching.

## Game names
Prop, scenario and native names are checked against the redm-info data files (objects.lua, Scenarios.lua)
and femga's rdr3_discoveries natives list.

No code from any VORP resource (GPL v2) is used.
