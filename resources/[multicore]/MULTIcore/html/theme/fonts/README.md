# Game fonts (optional)

MULTIcore's menus look most like Red Dead Redemption 2 with the game's own style of fonts. They are not included in the public release, because the font files belong to their owners. Drop them in this folder with exactly these names:

| File | Used for | What to use |
|---|---|---|
| `title.ttf` | titles and headings | the RDR "Lino" / "Chinese Rocks" style title font |
| `body.ttf` | normal text | Hapna Slab Serif (regular) |
| `body-medium.ttf` | menu rows, buttons | Hapna Slab Serif (medium) |
| `body-bold.ttf` | money, values | Hapna Slab Serif (bold) |

Many RedM servers already have these in other scripts' `fonts` folders. Without them, MULTIcore uses close free fonts (Oswald for titles, Zilla Slab for text), so everything still works.
