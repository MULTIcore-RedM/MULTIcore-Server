# MULTIimages

The item picture folder for MULTIinventory and MULTIstores. No pictures are included: put your own
`.png` files in `images/`, named exactly as each item's `image` field (`bread.png`, `weapon_revolver_cattleman.png` ...).

```
ensure MULTIimages     # anywhere after MULTIcore
```

The inventory finds them at `nui://MULTIimages/images/` (the first entry of `Config.ImagePaths` in MULTIinventory's config.lua).

GPL-3.0-or-later, part of MULTIcore by RINGO (RINGOscripting). The pictures you add are yours, under their own terms.
